## 本地库

- SQLite 文件：应用数据目录下的 `fcalendar.db`（Windows 为 `%APPDATA%\com.f.cal\`）
- 已有数据时可以用 `ALTER TABLE ... ADD COLUMN` 加列；有行时不能加「无 DEFAULT 的 NOT NULL」。旧迁移不改，只追加新版本（`rusqlite_migration`）。
- `r2d2` 通过 **`r2d2_sqlite`** 连接 `rusqlite`（方案未写但技术上必需）。
- 表（`001_init`）：`accounts`、`calendars`、`events`、`todos`、`alarms`、`memos`、`change_queue`、`conflicts`。
- 纯本地日历：`calendars.account_id` 为空。
- 事件/待办：`ics` 为同步真源，其余列为查询投影；`(calendar_id, uid)` 唯一。
- 首次启动：若没有任何日历，预置 1 个本地日历，显示名「本地」，颜色留空。

目标：本地数据库可用 + 前端简单月视图 + 左侧任务区 Inbox，用来验证读写与排期。

包含：

- 日历 + VEVENT 的本地 CRUD（Tauri command + Vue Query）

- 自绘**月视图**（周带子滚动）
- 月视图内新建 / 编辑 / 删除
- 左侧**任务区**：未排期**任务** + **图章** Inbox，拖到月格子生成全天**事件**

- 写 `change_queue`
- 网络同步与 Radicale 通信
- 地点、status 表单字段

## 事件写入约定

- 带时刻：ISO-8601 **含偏移**（如 `2026-09-17T10:00:00+08:00`）
- 全天：`YYYY-MM-DD`；ICS 的 `DTEND` 按 RFC 5545 开区间处理
- 表里暂无独立 `timezone` 列；偏移先保住绝对时间，夏令时 / TZID 以后再加列
- 可写 `rrule` 字符串并编进 ICS；**库内不展开实例**
- 仅当该事件所属日历的 `account_id` 非空时，本地写入才 `dirty=1`
- 本切片不写 `change_queue`（同步引擎再做）

## 重复规则（RRULE）

- 前端用**预设选项**（及以后的自定义面板）生成规则，不让用户手写 RRULE 字符串；后端仍收字符串。
- 月视图：按**可见月份窗口**在内存展开，不写回库。
- 点任意实例的编辑 / 删除都作用在**整组**（改主事件）。不做「仅此次」（无 EXDATE / 例外实例）。

## 月视图表单字段

- 要：标题、全天开关、开始、结束、重复、备注
- 不要：地点、status（`CONFIRMED` / `TENTATIVE` / `CANCELLED`）
- 标题必填；删除在对话框内且需确认
- 重复预设：不重复 / 每天 / 每周（同星期几） / 每月（同号） / 每年；无结束条件、无自定义 RRULE 面板
- 表单全天结束日按**含当日**填写；写入 ICS / 库时 `DTEND` 按 RFC 5545 开区间（+1 天）
- 点空白日 → 对话框新建（预填该日；默认非全天、结束 = 开始 + 1 小时）
- 点事件 → 同一对话框编辑
- 点任意重复实例，改/删整组

## 预览布局与窗口

- 窗口：`decorations: false` 自绘顶栏；默认 **1600×900**、可缩放；预览不做 Snap 预览、不做 Win11 圆角特化
- 顶栏可拖窗口（`data-tauri-drag-region`）；右上自绘最小化 / 最大化 / 关闭为**全局**控件（不属于某一视图；Tauri `core:window` 权限）
- 三栏：固定 **80px** 左边栏（拖窗口）| 任务区默认 **360**、最小 **320** | 右侧当前日历视图
- 全局顶栏右侧：视图下拉（切月按钮组与窗口三控件之间；当前仅「月视图」）+ 窗口三控件
- 左边栏一个文本按钮收起/打开任务区
- 任务区与月视图之间分割线可拖：缩到 320 仍显示；**同一次拖动左移距离超过按下时任务区宽度的 2/3** 则隐藏
- 拖藏后按钮展开回到 **320**；点按钮收起则记住当时宽度，再展开恢复该宽度
- 月视图在全局顶栏左侧：中文年月份；其右：Lucide 图标切月（`ChevronLeft` 上个月、`Circle` 回到当前月、`ChevronRight` 下个月；`title` 保留中文提示）
- 顶栏拖动区不要盖住切月按钮、视图下拉和窗口三按钮（按钮组 `@pointerdown.stop`）
- 无边框窗口在 Windows 上 `isMaximized()` 不可靠：最大化前记住 inner size + outer position；图标 `□` / `❐` 用本地状态；还原时 `unmaximize` 后再按记住的尺寸设回去。额外权限：`unmaximize`、`is-maximized`、`inner-size`、`outer-position`、`set-size`、`set-position`、`current-monitor`
- 拖任务区分割线时禁止文本选中（`user-select: none` + 指针捕获）
- 周一到周日单独一行固定在月网格**上方**，不写进第一周日期格子
- 月网格撑满顶栏与星期行之下的剩余高度；视口**固定显示 6 行**天格，行高等分剩余高度
- 月视图**自绘周带子**（预览切片不用 Schedule-X 月网格；`@schedule-x/*` 依赖保留给以后周/日视图）
- 天格子可**自由上下滚动**；整周行用 CSS `scroll-snap` 吸附（视口内不出现半行），惯性与对齐同一段滚动，**不**等停稳后再二次强制滚动，也**不强制**滚到月初
- **月初卡点**（该月 1 号所在周的周一贴顶）仅用于顶栏年月判断与切月按钮
- **4 周月**（28 天且 1 号为周一，如 2027-02）：切月卡点上移一周，视口为「上月 1 周 + 本月 4 周 + 下月 1 周」居中
- 5 / 6 周月：切月后首行即月初周；5 周月底行自然露出下一周
- 顶栏年月在**滚动途中**按离当前 `scrollTop` 最近的卡点月更新；切月按钮滚到对应卡点（不瞬间换页）
- 非当前月日格变淡；格子底色与格内事件颜色均与本月区分
- 切月以顶栏年月为唯一源；`list_events` 按**已挂载周带子**的首末日拉取（不因滚动途中顶栏变化反复请求）
- 一周从周一起；界面中文
- 仅月网格；不做**事件**拖拽改期
- 带时刻事件展示：`Temporal.Instant.from(含偏移 ISO)` → 系统 IANA 时区的 `ZonedDateTime`；全天用 `PlainDate`，结束日按库返回的**含当日**
- 跨天事件在每一天各显示一条（不做跨列色条）
- **日格四角**（离线 `tyme4ts`，不进 SQLite）：左上公历；右上仅国务院放假安排中的 **「假」**（休）或 **「班」**（调休补班），普通周末/工作日不标；左下农历（初一显示换月名如「九月」「闰六月」，其余显示「初二」「廿一」等）；右下节日 / 节气，**最多 2 个**
- 右下优先级：**重大传统/法定节日**（除夕、春节、元宵、端午、七夕、中秋、重阳、腊八、小年、元旦、妇女节、劳动节、青年节、儿童节、建党节、建军节、教师节、国庆等）> **二十四节气** > 其余纪念日。若节日名与当天节气相同或仅为节气名加「节」（如清明节 / 冬至节），**只保留节气**。同时有节日和节气时：节日在左、节气在右
- 传统节日**加粗、不用红色**。节气字色（仅本月）：春桃粉、夏墨绿、秋深黄、冬亮蓝。非本月格子的节气与节日用变淡的次要字色，不用四季色
- 中间事件条数按「周行高 − 顶栏 − 底栏农历/节日 − 预留 +x 行」动态计算；不足显示全部时，在最靠下可见事件下方显示圆圈 **+x**（x = 未显示条数），点击后在日格旁 Popover 列出全部事件标题，点标题与日格内一致（编辑整组）；点格子空白仍新建

## 预览 Tauri Commands

- `list_calendars`（内部用，界面不展示切换）
- `list_events(from, to, calendarId?)`：过滤软删，返回展开后的实例 + 主事件 id；实例 id = `{主事件id}_{去掉:-+:T 的 dtstart}`（不用冒号，以便 Schedule-X）
- `get_event` / `create_event` / `update_event` / `delete_event`（软删 `deleted_at`）
- `list_tasks` / `create_task` / `update_task` / `delete_task`（本地 `tasks` 表，硬删）
- 预览本地日历无 `account_id`，`dirty` 恒为 0；不写 `change_queue`

## 任务区 Inbox（任务 / 图章）

- **称呼**：任务区里是**任务**与**图章**；月格子里是**事件**（VEVENT）。
- **布局**：任务列表在上（默认可展开）；图章在下（**默认收起**）。两区标题行均可收起/展开；收起状态不持久化，每次打开应用图章仍默认收起。
- **加号**：整个任务区右上角**唯一**加号；永远在**任务列表顶部**插入行内草稿（若任务区被左边栏按钮隐藏则先展开任务区）。不在分组标题上单独放加号。
- **行内新建**：不弹窗；回车或失焦时标题非空才 `create_task`；空则丢弃。Escape 取消草稿。同时只允许一条草稿；连点加号只聚焦已有草稿。
- **单击 / 双击**：左键单击列表项无行为（避免与拖动混淆）。左键双击仅行内改标题；空标题失焦恢复原值，不删项。
- **编辑对话框**：项右侧三点 hover 显示；点三点或右键项 → 完整对话框（标题、是否图章开关、备注；删除在左，取消/确定在右）。删除需 `confirm`。点遮罩不关，靠取消/确定。
- **任务 ↔ 图章**：对话框改开关并确定、或拖到另一列表，立刻换组并放到目标列表顶部。
- **拖到月格子**：复制**标题 + 备注**到当前预览日历（唯一「本地」日历），`create_event` 为**全天**、目标日、不重复。普通任务拖完从列表删除；图章保留（同一天可盖多次）。盖出的事件与模板互不影响；改图章/任务模板只能在任务区。
- **拖放视觉**：落点高亮（天格子 / 任务列表 / 图章列表）。光标：图章→日历为复制，任务→日历为移动。拖放完成后短时忽略天格点击，避免误开新建事件框。
- **存储**：`tasks` 表字段 `id, summary, description, is_stamp, sort_order, created_at, updated_at`；无 `calendar_id` / `ics`。将来是否当 VTODO 同步**未定**。
- **列表排序**：组内按 `sort_order` 升序；新建或换组到顶部时取该组最小 `sort_order - 1`。

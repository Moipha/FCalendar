## CalDAV

- 第一家对接：**Radicale**
- 凭据不进 SQLite，只存 `credential_ref`；密码用 Rust **`keyring`（`windows-native`）** 写入 **Windows 凭据管理器**（`credential_ref` = `account-{账户 id}`，服务名 `com.f.cal`；读取时兼容旧版 `account/{id}`）。
- CalDAV 请求一律把集合 / 对象 href 拼成**绝对 URL**（相对路径接到登录时的 `server_url`）。前端 DevTools 里的 `http://ipc.localhost/<command>` 是 Tauri 调用，不是发往日历服务器的地址。
- **同一时间一个账户**：不支持多账户同时登录，也不在界面上同时展示多个账户的数据。
- **当前日历本**：设置里选择；**唯一读写目标**（事件、任务、图章、日格颜色的新建/改/删/同步上推都只打这一本）。不做「看多本、只写一本」。
  - 登录前选项只有预置「本地」。
  - 登录后选项 = 「本地」+ 该账户下已发现的各集合 + **新增日历本**。
  - 切到某本时立刻显示该本**本地已缓存**的数据，后台再同步；不要先清空再转圈。
  - **退出登录**后选项只剩「本地」，并切回「本地」。有未同步的远端改动时**禁止直接退出**：须先同步成功，或用户明确选择**放弃**这些改动后再退出。
- **登录会话**：退出之前本机一直算已登录（账户行 + 钥匙串密码还在）。下次开软件用已存凭据**后台自动连接**，不必再输密码。
  - 自动连接成功前、以及已登录但无网：仍可选各远端本，编辑**只改本地缓存**（dirty / 队列），连上后再同步。
  - **无网**：左边栏设置图标上方显示**离线（红）**，**不 Toast**。
  - **密码无效（401/403）**：Toast「密码无效，请到设置重新输入」，并引导打开设置改密（只写钥匙串，不退出）；状态点为红且可点开设置。**保持已登录 + 离线缓存**，不踢回「仅本地」。
  - **在线**：设置图标上方**在线（绿）**。未登录不显示状态点。
- **一本日历 = 一个工作区**：任务、图章、日格颜色与 VEVENT **写在当前选中的同一集合**。**不做额外集合**。图章按集合区分，不跨集合共用模板。不考虑其他客户端如何展示这些对象。
- **ICS 映射**（往返：以已存 `ics` 为底，只改认识的字段，保留未知属性 / VALARM 等）：
  - **事件**：VEVENT（现有字段：SUMMARY、DESCRIPTION、DTSTART/DTEND、RRULE）。
  - **任务**：无 `DTSTART` 的 VTODO；`X-FC-SORT-ORDER`。
  - **图章**：无 `DTSTART` 的 VTODO + `X-FC-IS-STAMP:1` + `X-FC-SORT-ORDER`。不加 `X-FC-KIND`。
  - **日格颜色**：每天一条 VJOURNAL，`X-FC-DAY-COLOR=green|red`，UID 固定 `fc-daycolor-YYYY-MM-DD`；清除 = 删除该对象。
  - 识别：任务 = 无 DTSTART 的 VTODO；图章看 `X-FC-IS-STAMP`；颜色只认带 `X-FC-DAY-COLOR` 的 VJOURNAL。
- **新增远端日历本**：默认空集合（`MKCALENDAR`），创建时可带 **`calendar-color`**（与 Radicale 网页端一样）。对象必须写在该集合目录内（集合 URL 以 `/` 结尾再拼接 `{uid}.ics`）。可选**从本地迁移**（拷事件 + 任务 + 图章 + 日格颜色到新集合）。迁移后二选一：**清空本地**，或**保留本地**。若保留：本地与迁出的那本远端**从此无关**——改远端不同步回本地，改本地也不再自动推到那本（除非用户之后又对本地做别的迁移）。
- **外观 / 日历 / 概览等设置**只存本机（`localStorage`），不上传 CalDAV。
- **同步（当前本）**：只同步设置里选中的、且 `account_id` 非空的日历本（事件 / 任务 / 图章 / 日格颜色）。本地日历不入队、不上传。拉时**不得用远端覆盖本地 dirty**。推：`If-Match`；412 则无条件 PUT（后写）。删除远端 404 视为成功。离线可切日历本，**不可新建**远端集合。
- **发现**：设置 → **账户** 连接 / 断开 / 重新发现；`PROPFIND` 走 `.well-known/caldav` → `current-user-principal` → `calendar-home-set` → Depth:1 列出集合。
- 连接允许 **`http://`**；HTTPS 使用 **跳过证书校验**（本机 / 局域网自签）。
- **冲突（现阶段）**：**后写覆盖**（谁最后成功传到服务器谁赢；按对象，不是整本日历）。多设备时可能盖掉另一台已同步的修改，已知不合理；以后可能改成类似 git 的用户合并，届时再改文档。同步时**不得用远端干净覆盖尚未上推的本地 dirty 对象**（否则离线编辑会被拉下来的旧/新远端直接抹掉）。

## 本地库

- SQLite 文件：应用数据目录下的 `fcalendar.db`（Windows 为 `%APPDATA%\com.f.cal\`）
- 已有数据时可以用 `ALTER TABLE ... ADD COLUMN` 加列；有行时不能加「无 DEFAULT 的 NOT NULL」。旧迁移不改，只追加新版本（`rusqlite_migration`）。
- `r2d2` 通过 **`r2d2_sqlite`** 连接 `rusqlite`（方案未写但技术上必需）。
- 表（`001_init`）：`accounts`、`calendars`、`events`、`todos`、`alarms`、`memos`、`change_queue`、`conflicts`。
- 纯本地日历：`calendars.account_id` 为空。
- 事件/待办：`ics` 为同步真源，其余列为查询投影；`(calendar_id, uid)` 唯一。
- 首次启动：若没有任何日历，预置 1 个本地日历，显示名「本地」，颜色留空。

## 事件写入约定

- 带时刻：ISO-8601 **含偏移**（如 `2026-09-17T10:00:00+08:00`）
- 全天：`YYYY-MM-DD`；ICS 的 `DTEND` 按 RFC 5545 开区间处理
- 表里暂无独立 `timezone` 列；偏移先保住绝对时间，夏令时 / TZID 以后再加列
- 可写 `rrule` 字符串并编进 ICS；**库内不展开实例**
- 仅当该事件所属日历的 `account_id` 非空时，本地写入才 `dirty=1`
- 本切片不写 `change_queue`（同步引擎再做）

## 重复规则（RRULE）

- 前端用**预设选项**（及以后的自定义面板）生成规则，不让用户手写 RRULE 字符串；后端仍收字符串。
- 月视图：按**可见月份窗口**在内存展开，不写回库。
- 点任意实例的编辑 / 删除都作用在**整组**（改主事件）。不做「仅此次」（无 EXDATE / 例外实例）。

## 月视图表单字段

- 要：标题、全天开关、开始、结束、重复、备注
- 不要：地点、status（`CONFIRMED` / `TENTATIVE` / `CANCELLED`）
- 标题必填；删除在对话框内且需确认
- 重复预设：不重复 / 每天 / 每周（同星期几） / 每月（同号） / 每年；无结束条件、无自定义 RRULE 面板
- 表单全天结束日按**含当日**填写；写入 ICS / 库时 `DTEND` 按 RFC 5545 开区间（+1 天）
- 点空白日 → 对话框新建（预填该日；默认非全天、开始 = 当前时刻、结束 = 开始 + 1 小时）
- 勾选全天：开始/结束换成**仅日期**输入（不显示时刻，也不填 00:00–23:59）。取消全天：恢复为该日的「当前时刻 → +1 小时」。勾选状态与时刻不受标题 / 备注输入影响
- 窗口三控件层级高于弹窗遮罩，弹窗打开时仍可最小化 / 最大化 / 关闭
- 点事件 → 同一对话框编辑
- 点任意重复实例，改/删整组

- 周一到周日单独一行固定在月网格**上方**，不写进第一周日期格子

- 月视图**自绘周带子**（预览切片不用 Schedule-X 月网格；`@schedule-x/*` 依赖保留给以后周/日视图）
- 周带子**数据**仍整条持有（初始 ±6 月，边缘 +13 周）；**DOM** 只挂视口 6 行 + 上下各 4 周（`OVERSCAN=4`）的日格内容，占位高度 = 周数 × 行高，可见周行绝对定位；另对整条带子挂无内容 snap 占位行以配合 `scroll-snap-type: mandatory`；滚动时按 `scrollTop` 切片更新内容挂载范围
- 农历信息按当前挂载日期**增量缓存**；跳月重建带子时清空缓存
- 天格子可**自由上下滚动**（隐藏滚动条，滚轮 / 触控板仍可用）。默认整周行用 CSS `scroll-snap` 吸附（视口内不出现半行），可在设置中关闭「滚动贴合周边界」后自由停在半行；切月 / 回今天 / 选日期仍滚到月初卡点。惯性与对齐同一段滚动，**不**等停稳后再二次强制滚动，也**不强制**自由滚动时滚到月初
- **月初卡点**（该月 1 号所在周的**周首**贴顶；周首由设置「一周从」决定，默认周一）仅用于顶栏年月判断与切月按钮
- **4 周月**（28 天且 1 号恰为周首，如周一起算的 2027-02）：切月卡点上移一周，视口为「上月 1 周 + 本月 4 周 + 下月 1 周」居中
- 5 / 6 周月：切月后首行即月初周；5 周月底行自然露出下一周
- 顶栏年月在**自由滚动途中**按离当前 `scrollTop` 最近的卡点月更新。切月按钮、回今天、选日期：顶栏**立刻**切到目标月并锁定，平滑滚到卡点途中不跟 `scrollTop` 改写（避免 scroll-snap 经过中间月时闪烁）
- 非当前月日格变淡；格子底色与格内事件颜色均与本月区分
- 切月以顶栏年月为唯一源；`list_events` 按**已挂载周带子**的首末日拉取（不因滚动途中顶栏变化反复请求）
- **一周从**可在设置中选周一（默认）或周日；星期行标签与周网格、多选区间顺序随周首旋转；界面中文
- 仅月网格；事件可拖到其他日格或任务区（见下），不做边缘拉伸
- 带时刻事件展示：`Temporal.Instant.from(含偏移 ISO)` → 系统 IANA 时区的 `ZonedDateTime`；全天用 `PlainDate`，结束日按库返回的**含当日**
- 跨天事件在每一天各显示一条（不做跨列色条）
- **日格四角**（离线 `tyme4ts`，不进 SQLite）：左上公历；右上仅国务院放假安排中的 **「假」**（休）或 **「班」**（调休补班），普通周末/工作日不标；左下农历（初一显示换月名如「九月」「闰六月」，其余显示「初二」「廿一」等）；右下节日 / 节气，**最多 2 个**
- 右下优先级：**重大传统/法定节日**（除夕、春节、元宵、端午、七夕、中秋、重阳、腊八、小年、元旦、妇女节、劳动节、青年节、儿童节、建党节、建军节、教师节、国庆等）> **二十四节气** > 其余纪念日。若节日名与当天节气相同或仅为节气名加「节」（如清明节 / 冬至节），**只保留节气**。同时有节日和节气时：节日在左、节气在右
- **重要节日**（右下 `major`）：加粗 + **主题色**。可在设置关闭「显示次要节日」，则右下不渲染未加粗的 `minor`；重要节日与节气仍按原优先级最多 2 个。**节气**字色（仅本月）由设置四色取色器控制（默认春 `#d4537e`、夏 `#1f6b4a`、秋 `#c47a12`、冬 `#2f7ae5`），写 CSS 变量 `--fc-jieqi-*`。非本月格子的节气与节日用变淡的次要字色，不用四季色
- 中间事件条数按「周行高 − 顶栏 − 底栏农历/节日 − 预留 +x 行」动态计算；不足显示全部时，在最靠下可见事件下方显示圆圈 **+x**（x = 未显示条数），点击后在日格旁 Popover 列出全部事件标题，点标题与日格内一致（编辑整组）；点格子空白仍新建
- **日格多选**（整格有效；按住 Ctrl / Shift 时不新建、不编辑、不拖动事件）：**Ctrl + 左键**切换该格选中，锚点改到该格（取消选中后锚点仍留该格）。**Shift + 左键**：有锚点时选中变为锚点到该格整段（按周带子日期顺序，含非本月），段外原先 Ctrl 单选取消，锚点不动；无锚点时同 Ctrl + 左键。**Ctrl + Shift + 左键**：锚点到该格整段并入现有选中，段外已选保留，锚点不动；无锚点时同 Ctrl + 左键。普通左键：已有选中则只清空选中与锚点、不新建；无选中则新建。选中为沿格子内缘流动的 2px 主色虚线，日格内文字不可选中。`Escape` 先关菜单再清选中；滚动、切月不清选中。选中仅存前端，不写库
- **日格右键菜单**（整格有效：空白、事件条、+x）：`Teleport` 到 `body`、光标处定位，同时只保留一个；拖动进行中不打开；若 +x 浮窗已开则先关。**点多格选中中的任一格**（选中数 > 1）：不取消选中，菜单无「创建新的事件」，打开时冻结日期列表。最上 **清除日格颜色**（Eraser，至少一格非默认才显示）清列表内全部底色；**设置日格颜色** 对列表内每一格统一设色（预览色为右键那一格）。**点未选中格**：先清选中再开单格菜单。单格菜单：已有浅绿/浅红时最上显示 **清除日格颜色**，其下 **创建新的事件**（加号）、**设置日格颜色**；色块行空白处收起色块。选色 / 清除后立刻改底色并关菜单。点菜单外关菜单并抑制紧随其后的左键；月网格滚动只关菜单不改色
- **日格底色**：`day_colors` 按 `calendar_id` 分桶（`date` + `green`/`red`）。远端本写入同一集合的按日 VJOURNAL。默认 = 无行。预设三种：默认（白底 + 现有浅灰悬浮）、浅绿、浅红（各自有更浅悬浮色，较先前更淡）。非本月仍对底色做与默认一致的变淡，且**不**随悬浮改色。今天内描边、拖放落点高亮逻辑不变
- **事件拖动**：格内事件条与 +x 浮窗内条目同一套；移动超过约 5px 进入拖动，单击仍编辑整组。拖动预览为跟随指针的**标题**（非 ghost 条，任务拖亦同）。一旦进入拖动立刻关闭 +x 浮窗。事件条最左侧有一条与日格背景同色的小竖线，表示可拖动（悬停 / 落点高亮时随格子底色变化）
- 拖到**其他日格**：整组相对平移改期（按抓取日算日差；带时刻只改日历日、时刻与时长不变；跨天全天整段平移；重复事件整组平移并保留 `rrule`）。拖回起始日格或无效区域不写库
- 拖到**任务 / 图章列表**：转换成 Inbox（`create_task` 标题+备注，再 `delete_event` 删整组；重复系列全部消失）。落到任务 → 普通任务，落到图章 → 图章
- 任务区被左边栏隐藏时无落点、不自动展开；拖到视口边缘不自动滚月网格

## 预览 Tauri Commands

- `list_calendars`（内部用，界面不展示切换）
- `list_events(from, to, calendarId?)`：过滤软删，返回展开后的实例 + 主事件 id；实例 id = `{主事件id}_{去掉:-+:T 的 dtstart}`（不用冒号，以便 Schedule-X）
- `get_event` / `create_event` / `update_event` / `delete_event`（软删 `deleted_at`）
- `list_tasks` / `create_task` / `update_task` / `delete_task`（本地 `tasks` 表，硬删）
- `list_day_colors(from, to)` / `set_day_color(date, color?)` / `set_day_colors(dates, color?)`（本地 `day_colors`；`color` 空则删行恢复默认）
- 预览本地日历无 `account_id`，`dirty` 恒为 0；不写 `change_queue`

## 任务区 Inbox（任务 / 图章）

- **称呼**：任务区里是**任务**与**图章**；月格子里是**事件**（VEVENT）。
- **布局**：任务列表在上（默认可展开）；图章在下（**默认收起**）。两区标题行均可收起/展开；收起状态不持久化，每次打开应用图章仍默认收起。
- **加号**：整个任务区右上角**唯一**加号；永远在**任务列表顶部**插入行内草稿（若任务区被左边栏按钮隐藏则先展开任务区）。不在分组标题上单独放加号。
- **行内新建**：不弹窗；回车或失焦时标题非空才 `create_task`；空则丢弃。Escape 取消草稿。同时只允许一条草稿；连点加号只聚焦已有草稿。
- **单击 / 双击**：左键单击列表项无行为（避免与拖动混淆）。左键双击仅行内改标题；空标题失焦恢复原值，不删项。
- **编辑对话框**：项右侧三点 hover 显示；点三点或右键项 → 完整对话框（标题、是否图章开关、备注；删除在左，取消/确定在右）。删除需 `confirm`。点遮罩不关，靠取消/确定。
- **任务 ↔ 图章**：对话框改开关并确定、或拖到另一列表，立刻换组并放到目标列表顶部。
- **拖到月格子**：复制**标题 + 备注**到当前预览日历（唯一「本地」日历），`create_event` 为**全天**、目标日、不重复。普通任务拖完从列表删除；图章保留（同一天可盖多次）。盖出的事件与模板互不影响；改图章/任务模板只能在任务区。
- **拖放视觉**：落点高亮（天格子 / 任务列表 / 图章列表）。光标：图章→日历为复制，任务→日历为移动。拖动预览为跟随指针的标题。拖放完成后短时忽略天格 / 事件条点击，避免误开对话框
- **列表展开**：开始拖任务或事件**不再**自动展开收起的列表；拖到某列表**标题**（含收起态）上时在拖动中展开该列表，展开后保持，可落在标题或列表区
- **存储**：`tasks` 挂 `calendar_id`；远端本为无 DTSTART 的 VTODO（图章 `X-FC-IS-STAMP`）。图章不跨集合。
- **列表排序**：组内按 `sort_order` 升序；新建或换组到顶部时取该组最小 `sort_order - 1`。

## 概览侧栏页

- 显示名「概览」。单独 `list_events`（今天 → 今天 + N 天），不复用月网格查询；查询键挂在 `events` 前缀下，月视图增删改 / 拖放会一并刷新待进行列表。
- **下次放假**：放假日 = 国务院「假」，或周六日且非「班」。今天已是放假日则文案「今天放假中」。否则从当前时刻算到下一个放假日 0:00，口语化：不足 12 小时「不到半天」；满 12 小时未满 24 小时「一天」；之后每 12 小时一档（一天半 / 两天 / 两天半…）。数量 2 读「两」不读「二」。数字/词组主题色加粗。
- **待进行**：从现在起未结束的事件（全天按结束日含当日；带时刻按 `dtend`）。默认 N=7，设置可改为 14 / 30。按开始时间排；点一行打开现有编辑弹窗（改/删整组）。标题行右侧 `ChevronDown` / `ChevronRight` 可收起/展开列表，**默认展开**，不持久化。

## 设置

- 左边栏底图标打开弹窗；点遮罩不关，靠取消/确定。窗口三控件仍在遮罩之上。打开时拷进草稿，**确定**写入 `localStorage` 并生效，**取消**丢弃草稿。
- 存储键 **`fc.settings.v1`**（JSON 一份偏好）；旧键 `fc.settings.upcomingDays` 首次读取时迁移后删除。**不上传 CalDAV**（主题色、周首、节气色、待进行天数等只跟本机）。
- **外观**：主题色（系统取色器 + 预设色块：默认近黑、蓝、绿、琥珀、玫红）写入后改 `:root` 的 `--primary` / `--primary-foreground`（字色按亮度自动浅/深）。影响确定按钮、今天数字圆底与日格描边、选中流动虚线、事件条淡底、拖放高亮、概览放假倒计时、多选菜单描边、设置里单选/多选框的 `accent-color` 等已用 `primary` 的 UI。四节气色各一取色器，旁有「恢复默认」。
- **日历**：一周从（周一 / 周日，默认周一）；「显示次要节日」（默认开）；「滚动贴合周边界」（默认开，关则月网格无 mandatory snap）。
- **概览**：「待进行」天数 7 / 14 / 30（默认 7）。

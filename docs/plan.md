# Local-First CalDAV 桌面客户端技术方案与软件规划

## 1. 项目定位与架构理念

- **产品定位**：一款基于 Local-First（本地优先）架构的桌面端日历、待办与备忘管理软件。
- **目标平台**：优先 Windows 桌面端，架构需兼容后续向 Android 迁移（基于跨平台逻辑复用）。
- **架构模式**：**纯客户端模式（0 Server）**：不架设任何自建中继服务器，由客户端直接与用户的 CalDAV 服务端（如 iCloud、Nextcloud、Radicale 等）通信。**本地优先（Local-First）**：所有读写交互优先走本地数据库，保证秒开与无网络离线可用；网络同步作为后台异步任务执行。**双层结构职责**：**前端（Vue 3）**：专注于界面呈现、视图自适应、日历网格交互、用户输入与状态调度。**后端（Rust Core）**：专注于本地持久化、网络协议通信、数据加解密、iCalendar 格式解析与重复规则计算、系统级能力调用。

## 2. 选定技术栈矩阵

### 2.1 前端技术栈 (Frontend UI)

| 模块             | 选定方案                               | 选型考量                                                     |
| ---------------- | -------------------------------------- | ------------------------------------------------------------ |
| **基础框架**     | **Vue 3 + TypeScript**                 | 响应式开发效率高，组件化架构清晰                             |
| **构建工具**     | **Vite**                               | 快速热更新与高效静态构建                                     |
| **日历核心视图** | **Schedule-X v4 (@schedule-x/vue)** + **自绘月网格** | Schedule-X 保留给以后周/日视图；预览月视图为自绘「周带子」滚动网格（6 行视口、自由滚 + 吸附）。v4 事件时间为 Temporal（`temporal-polyfill@0.3.0`） |
| **UI 组件库**    | **shadcn-vue**                         | 基于无样式原语组件，源码直接集成进项目，高自由度定制桌面级视觉质感 |
| **样式系统**     | **Tailwind CSS v4**                    | 原子化 CSS，便于窗口宽度变化时的自适应布局                   |
| **状态管理**     | **Pinia + TanStack Query (Vue Query)** | Pinia 管理客户端纯 UI 状态；Vue Query 负责 Tauri IPC 异步调用结果的本地缓存与乐观更新 |
| **日期工具**     | **date-fns**                           | 轻量函数式日期处理库，按需引入无沉重负担                     |

### 2.2 宿主与原生后端 (Tauri & Rust Core)

| 模块               | 选定方案                                 | 选型考量                                                     |
| ------------------ | ---------------------------------------- | ------------------------------------------------------------ |
| **桌面框架**       | **Tauri (v2)**                           | 相比 Electron 体积极小、内存占用低，Rust 底层性能极强        |
| **本地持久化**     | **rusqlite + r2d2 + r2d2_sqlite + rusqlite_migration** | 原生 SQLite 驱动；连接池保障多线程读写并发；迁移工具支持后续无感升级数据库版本 |
| **网络通信**       | **reqwest (启用 rustls-tls)**            | 纯异步 HTTP 客户端，原生支持 WebDAV 自定义方法，规避 Windows 对外部 OpenSSL 动态库的依赖 |
| **协议报文解析**   | **quick-xml**                            | 极速流式解析 WebDAV Multi-Status XML 响应                    |
| **规则与数据处理** | **rrule + icalendar + chrono + uuid**    | 纯 Rust 负责 iCalendar (RFC 5545) 生成，后台按可见窗口展开 RRULE；事件 UID 用 uuid v4 |
| **系统级原生特性** | **Tauri 官方插件集 + 核心 tray-icon**    | plugin-notification（系统通知）<br>tauri `tray-icon` feature（托盘，无独立 plugin-tray）<br>plugin-single-instance（单实例）<br>plugin-autostart（开机自启，预览不默认 enable） |

## 3. 软件功能范围规划

### 3.1 核心业务模块

1. **多日历源管理**支持添加符合 CalDAV 标准的第三方账户。支持多日历集合发现、显示/隐藏勾选、自定义日历颜色。
2. **日程管理 (VEVENT)**支持月视图、周视图、日视图与日程列表（Agenda）。支持普通事件、全天事件、跨天事件。支持复杂重复规则（RRULE，如每周、隔周、每月特定工作日等）。交互支持：点击查看/编辑、网格拖拽改期、边缘拉伸修改时长。
3. **待办与提醒事项 (VTODO + VALARM)**基于 CalDAV 原生 VTODO 协议实现，与主流待办系统（如 Apple 提醒事项、Nextcloud Tasks）兼容。支持设置截止时间、优先级、完成状态切换。到期本地精准桌面通知提醒。
4. **备忘录功能**作为本地轻量笔记/备忘模块，不强依赖 CalDAV 协议限制，采用本地存储保障纯粹的书写体验。

### 3.2 数据同步与离线机制规划

- **双向增量同步**：优先采用 WebDAV Sync-Collection（RFC 6578）的 Sync-Token 机制；降级支持 CTag 变更比对。
- **离线容错**：无网环境下允许任意 CRUD 操作；重新联网后后台静默队列自动上推变更。
- **并发与冲突策略**：利用 HTTP ETag 乐观锁；发生版本冲突时，默认保全远程内容并将本地修改另存副本，杜绝数据静默丢失。
